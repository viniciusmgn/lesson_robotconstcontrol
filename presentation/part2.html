WAYS TO MODEL GEOMETRY


  • In robotics, we need to represent the geometry of the robot and environment in a way that is convenient for calculations (such as computing distances).

  • Three main methods:

    • Convex shapes;

    • Point clouds;

    • Meshes;


GEOMETRIC REPRESENTATION

CONVEX SHAPES


  • Convex shapes (i.e., if two points are inside the shape, the line segment between them is also inside) are the simplest way to represent geometry.

  • More complex shapes (such as non-convex ones) can be decomposed into simpler convex shapes.

  • Pros: Simple and fast for calculations.

  • Cons: Decomposing a complex shape into simple convex shapes can be time-consuming, especially if it needs to be done in real time.

GEOMETRIC REPRESENTATION

CONVEX SHAPES


  • This is usually used when you know the geometry a priori.

  • For example, it is very reasonable to model a manipulator using convex geometries since its geometry is known beforehand.

  • For the environment, this applies, for example, to a warehouse where robots operate. The geometry of the warehouse is perfectly known, allowing sufficient time for pre-processing and decomposing parts into convex shapes.

CONVEX ANALYSIS BASICS

DEFINITION OF CONVEXITY


  • Convexity is a key property in geometry that will be necessary to our studies;

  • In some sense, it is the "linear algebra" of geometry: just like non-linearities can be studied by tools of linear algebra, non-convexity can be studded using tools from convexity theorem;

  • I will present (and discuss) some basic results here. If you want to know more, I recommend Chapter 3 of Boyd's classical book ;

CONVEX ANALYSIS BASICS

DEFINITION OF CONVEXITY


  • A set \(\mathcal{S} \subseteq \mathbb{R}^n\) is convex if for any two points in the set, the line that connects them is also in the set. Formally: $$\{ u_1, u_2 \in \mathcal{S}, \ u_1 \not= u_2 \ \rightarrow \ \forall \alpha \in [0,1]$$ $$\alpha u_1 + (1-\alpha) u_2 \in \mathcal{S}\};$$

CONVEX ANALYSIS BASICS

COMPACT SETS AND STRICT CONVEXITY


  • A set \(\mathcal{S}\) is said to be closed if, "essentially" (the formal definition is trickier), it contains its boundary, called \(\partial \mathcal{S}\).

  • A set is said to be bounded if there exists a ball of finite radius that covers it.

  • A set is said to be compact if it is closed and bounded.

  • A closed convex set is said to be strictly convex if the line that connects the points is contained entirely inside the set (not in the border), with the possible exception of the initial and final points. Intuitively, this means that the object's boundary has no "flat" sides. Formally: $$\{ u_1, u_2 \in \mathcal{S} \ , u_1 \not=u_2 \ \ \rightarrow \ \forall \alpha \in (0,1)$$ $$ \alpha u_1 + (1-\alpha) u_2 \in \mathcal{S}-\partial \mathcal{S}\};$$

CONVEX ANALYSIS BASICS

MINKOWSKY SUM AND SUBTRACTIONS


  • An important operation between sets is the Minkowski sum and subtraction:
    $$\mathcal{A} \oplus \mathcal{B} = \{ a + b , a \in \mathcal{A} , b \in \mathcal{B}\};$$ $$\mathcal{A} \ominus \mathcal{B} = \{ a - b , a \in \mathcal{A} , b \in \mathcal{B}\};$$
  • The Minkowski sum is the set of all possible pairwise sums of points in the two sets. If one set, say \(\mathcal{A}\), has its origin at the center, it can also be thought of as "sweeping" \(\mathcal{A}\) over the boundary of \(\mathcal{B}\).

  • Minkowski subtraction is simply the Minkowski sum between \(\mathcal{A}\) and the set of opposites of \(\mathcal{B}\), called \(-\mathcal{B}\). Thus, \(\mathcal{A} \ominus \mathcal{B} = \mathcal{A} \oplus (-\mathcal{B})\).

  • Defined for arbitrary sets but especially important for convex sets.

CONVEX ANALYSIS BASICS

PROPERTIES OF CONVEX SETS


  • Prop 1: the intersection of convex sets \(\mathcal{A} \cap \mathcal{B}\) is convex. This is not true for the union, though;

  • Prop 2: the cartesian product \(\mathcal{A} \times \mathcal{B}\) of convex sets is convex;

  • Prop 3: the Minkowsky sum and subtraction of convex sets is convex;

  • Prop 4: for any point \(u\) in the boundary of the set, consider the tangent hyperplane to the set at this point. The set is contained entirely in one of the sides of the hyperplane;

  • Prop 5 (Separating hyperplane theorem): if two sets are convex, either they have an intersection, or there is a separating hyperplane that separates them;

CONVEX ANALYSIS BASICS

CONVEX FUNCTIONS


  • A very useful way to handle convexity using analytic geometry is through convex functions.

  • A function \(f: \mathbb{R}^n \mapsto \mathbb{R}\) is said to be a convex function if \(\forall u_1, u_2 \in \mathbb{R}^n \ , u_1 \not= u_2, \alpha \in [0,1]\):
    $$ f(\alpha u_1+(1-\alpha) u_2) \leq \alpha f(u_1) + (1-\alpha) f(u_2);$$
  • Geometrically, this means two things:
    • That for any two points \((u_1,f(u_1))\) and \((u_2,f(u_2))\) on the graph, the function's plot is either touching or below the straight line connecting them.
    • That the epigraph, i.e., the \(n+1\)-dimensional set \( \mathcal{V} = \{u \in \mathbb{R}^n , v \in \mathbb{R} \ , \ v \geq f(u)\} \), is convex.

  • Example: \(f(u)=u^2\).

CONVEX ANALYSIS BASICS

STRICTLY CONVEX FUNCTIONS


  • A function \(f: \mathbb{R}^n \mapsto \mathbb{R}\) is said to be a strictly convex function if \(\forall u_1, u_2 \in \mathbb{R}^n \ , u_1 \not= u_2, \ \alpha \in (0,1)\):
    $$ f(\alpha u_1+(1-\alpha) u_2) < \alpha f(u_1) + (1-\alpha) f(u_2);$$

  • Note the difference from before: \(\alpha\) should lie in the open interval \((0,1)\) and it should be \(<\) other than \(\leq\);

  • As you probably expected, the epigraph is now strictly convex, and the plot of the graph should be strictly below the straight line, except for the starting and end points;

  • Example: the function \(f(u)=u^2\) is strictly convex, but \(f(u)=|u|\) is only convex;

CONVEX ANALYSIS BASICS

PROPERTIES OF CONVEX FUNCTIONS


  • Prop 1: if \(f,g: \mathbb{R}^n \mapsto \mathbb{R}\) is convex and \(A,B \geq 0\), the function \(h(u) = Af(u)+Bg(u)\) is also convex;

  • Prop 2: if \(f,g: \mathbb{R}^n \mapsto \mathbb{R}\) is convex, then \(h(u) = \max(f(u),g(u))\) is convex;

  • Prop 3: all convex functions are continuous. Furthermore, if it is differentiable, the derivative is bounded;

  • Prop 4: if \(f: \mathbb{R}^n \mapsto \mathbb{R}\) is convex and \(g: \mathbb{R}^m \mapsto \mathbb{R}^n\) is an affine function \(g(u)=Au+b\), then \(h(u)=f(g(u))\) is convex. Furthermore, if \(g\) is injective (i.e., \(g(u_1) = g(u_2) \rightarrow u_1 = u_2\) ) and \(f\) is strictly convex, so is \(h\);

CONVEX ANALYSIS BASICS

PROPERTIES OF CONVEX FUNCTIONS


  • Prop 5: if (but not only if) the function \(f(u)\) is convex, the sublevel sets \(\mathcal{L}(c) = \{u \in \mathbb{R}^n \ | \ f(u) \leq c\}\) for a constant \(c\) are convex. Furthermore, if \(f(u)\) is strictly convex, the sets are strictly convex. The function \(f(u) = \sqrt{|u|}\) is an example to the "only if" claim;

  • Thus, we can represent a convex sets as \(f(u) \leq 0\) for a convex function \(f\). Since the intersection of convex sets is also convex (see Prop 1 of convex sets), a convex set can be also characterized as $$\mathcal{S} = \{u \in \mathbb{R}^n \ | \ f_i(u) \leq 0 \ i = 1,...,n\};$$

  • This is specially useful for polyhedras (i.e., convex shapes with flat faces), which can be described like this when \(f_i(u) = a_i^\top u-b_i\) are affine functions.
Level sets of \(f(x,y) = x^2+y^4\).

CONVEX ANALYSIS BASICS

PROPERTIES OF CONVEX FUNCTIONS


  • Prop 6: convex functions have no local maxima (i.e., points \(u_{max}\) in which around every point has a smaller value );

  • Prop 7: For convex functions, all local minima (i.e., points \(u_{min}\) in which around every point has a larger value), if they exist, are global, that is, they achieve the smallest possible value for \(f(u)\). Furthermore, the set of local (global) minima is convex;

  • Prop 8: if \(f(u)\) is strictly convex, the set of global minima is either empty or a single point;

CONVEX ANALYSIS BASICS

PROPERTIES OF CONVEX FUNCTIONS


  • Prop 8: if the convex function \(f\) is differentiable, it is convex if and only if for all \(u_1,u_2\): $$ \nabla f(u_2)^\top (u_1-u_2) \leq f(u_1)-f(u_2);$$ In one dimension, this can be rewritten as \(f(u) \geq f'(u_0)(u-u_0)+f(u_0)\), which means that the graph of \(v=f(u)\) is always above the tangent line at any point \(u_0\);

  • Prop 9: if \(f(u)\) is two times differentiable, it is convex if and only if the Hessian matrix \(\frac{\partial^2 f}{\partial u^2}(u)\) is a positive semidefinite matrix for all \(u\);

  • Prop 10: if \(f(u)\) is two times differentiable, it is strictly convex if (but not only if) the Hessian matrix \(\frac{\partial^2 f}{\partial u^2}(u)\) is a positive definite matrix for all \(u\). The function \(f(u)=x^4\) is a counterexample to the "only if" claim;

CONVEX ANALYSIS BASICS

CONVEX OPTIMIZATION PROBLEM


  • We saw the definition of convex sets and convex functions. We now define a convex optimization problem: $$ \min_{u \in \mathcal{U}} f(u)$$ in which \(f: \mathbb{R}^n \mapsto \mathbb{R}\) is a convex function, and \(\mathcal{U}\subseteq \mathbb{R}^n\) is a convex set;

  • Overall, it is the easiest class of optimization problems. Generally, it can be solved very efficiently;

  • But why?

CONVEX ANALYSIS BASICS

CONVEX OPTIMIZATION PROBLEM


  • For the sake of simplicity, let's assume that \(f\) is differentiable and that \(\mathcal{U}=\mathbb{R}^n\) (i.e., no constraints).

  • One of the most powerful ideas in optimization (and applied mathematics) is gradient descent: if you want to minimize \(f(u)\), take steps in the direction opposite to the gradient \(\nabla f(u)\), starting from an initial point \(u[0]\): $$u[k+1] = u[k] - \eta[k] \nabla f(u[k]);$$ for some \(\eta[k] > 0\) (which may vary with \(k\)).

  • If the step size is chosen appropriately, the function \(f(u)\) will decrease as long as movement is possible, that is, as long as \(\nabla f(u) \not= 0\).

CONVEX ANALYSIS BASICS

CONVEX OPTIMIZATION PROBLEM


  • A major issue with this approach, which is the bane of (continuous) optimization, is local minima. At these points \(u\), \(\nabla f(u) = 0\), but the true minimum of \(f(u)\) is not achieved. Gradient descent can become trapped in a local minimum instead of reaching the true global minimum.

  • This is not a problem for convex functions because, as mentioned in Prop 7 earlier, convex functions only have global minima. Therefore, if \(\nabla f(u[k])=0\), we can be certain that we have reached a global minimum.

CONVEX ANALYSIS BASICS

CONVEX OPTIMIZATION PROBLEM


    • What if we have constraints, i.e., \(\mathcal{U} \neq \mathbb{R}^n\)?

    • Just follow the opposite of the gradient, as before.

    • If you converge to a point inside the set, you have reached a global minimum, which is the same as in the unconstrained problem.

    • If you reach the boundary of the set, project the opposite of the gradient onto the boundary and keep following it. If the projection is zero (i.e., the opposite of the gradient is parallel to the outward-pointing normal of the boundary), you can be sure you have found a global minimum.

    • But why can you be sure?

CONVEX ANALYSIS BASICS

CONVEX OPTIMIZATION PROBLEM


  • The intuitive argument (not a formal proof) follows by contradiction.

  • Let \(u_A\) be the point where we converged at the boundary. The convergence criterion implies that \(-\nabla f(u_A)\) is trying to "move outside" the set to further minimize \(f(u)\) (if there were no constraints).

  • Now, suppose there is another point \(u_B\) in \(\mathcal{U}\) with a smaller function value: \(f(u_B) < f(u_A)\).

  • The argument is that, in this case, for a convex function, \(-\nabla f(u_A)\) should "more or less" point in the direction from \(u_A\) to \(u_B\), which can be followed since \(\mathcal{U}\) is convex (i.e., the line connecting \(u_A\) and \(u_B\) remains inside the set).

  • This contradicts the assumption that \(-\nabla f(u_A)\) is pointing outward and that no further steps can be taken to decrease \(f(u)\).

  • The formal proof requires demonstrating that \(-\nabla f(u_A)\) should "more or less" point in the claimed direction when \(f(u)\) is convex. This is clearly the case, for example, when \(f(u) = 0.5\|u - u_B\|^2\).

CONVEX ANALYSIS BASICS

STRICTLY CONVEX OPTIMIZATION PROBLEM


  • A convex optimization problem is said to be strictly convex if \(f(u)\) is not only convex, but strictly convex (the set \(\mathcal{U}\) need not to be strictly convex);

  • The main interest of strictly convex optimization problem is as follows:

    Theorem: if the set \(\mathcal{U}\) is compact, a strictly convex optimization problem has a single optimal point.

  • Compactness is there only to ensure that a finite optima exist (e.g., take \(\mathcal{U} = \mathbb{R}\) and consider \(\min_{u \in \mathcal{U} } e^{-u}\) ).

  • This is not true for general convex problems (e.g., take \(\min_{u} \ (u_1-u_2)^2\));

CONVEX ANALYSIS BASICS

PARAMETRIZED OPTIMIZATION PROBLEMS AND THE ENVELOPE THEOREM


  • Let \(f: \mathbb{R}^n \times \mathbb{R}^m \mapsto \mathbb{R}\) be a function \(f(u,\theta)\) that is differentiable in both arguments and \(\mathcal{U} \subseteq \mathbb{R}^n\) be a set. Define the function: $$ F^*(\theta) = \min_{u \in \mathcal{U}} \ f(u,\theta); $$
  • This is a parametrized optimization problem, since \(\theta\) is a parameter to the optimization problem. Note that \(F^* : \mathbb{R}^m \mapsto \mathbb{R}\). We would like to compute the derivative of \(F^*\) on \(\theta\). For this:

    Theorem (Envelope Theorem): the derivative of \(F^*(\theta)\) exists for any \(\theta\) such that the minimizer of the optimization problem, \(u^*(\theta)\), is unique and finite. Furthermore: $$\frac{\partial F^*}{\partial \theta} (\theta) = \frac{\partial f}{\partial \theta}(u^*(\theta),\theta).$$

CONVEX ANALYSIS BASICS

PARAMETRIZED OPTIMIZATION PROBLEMS AND THE ENVELOPE THEOREM


  • Example: consider the optimization problem: $$ \min_{u \in \mathcal{U}} f(u,\theta)$$ in which \(f(u,\theta) = \theta_1 u_1 + \theta_2 u_2\) and \(\mathcal{U}\) is the circle \(u_1^2+u_2^2 \leq 1\);
  • The optimal solution is unique: \(u_1^*(\theta) = -\theta_1/\sqrt{\theta_1^2+\theta_2^2}\), \(u_2^*(\theta) = -\theta_2/\sqrt{\theta_1^2+\theta_2^2}\), unless \(\theta_1=\theta_2=0\), in which case, any \(u_1,u_2\) is optimal;

  • Making the substitution, \(F^*(\theta) = -\sqrt{\theta_1^2+\theta_2^2}\). Envelope theorem says that: $$\frac{\partial F^*}{\partial \theta} (\theta) = \frac{\partial f}{\partial \theta}(u^*(\theta),\theta) = \big(\begin{array}{c} u_1^*(\theta) \ \ u_2^*(\theta) \end{array}\big) = \frac{-\big(\begin{array}{c} \theta_1 \ \ \theta_2 \end{array}\big)}{\sqrt{\theta_1^2+\theta_2^2}}$$ which can be checked by inspection. Note that the derivative does not exist when \(\theta_1=\theta_2=0\);

CONVEX ANALYSIS BASICS

PARAMETRIZED OPTIMIZATION PROBLEMS AND THE ENVELOPE THEOREM


  • The utility of the theorem lies in the fact that we often cannot compute \(F^*(\theta)\) analytically (as we did in the previous example). However, we can compute \(\frac{\partial f}{\partial \theta}\) analytically and determine \(u^*(\theta)\) numerically, which allows us to compute the gradient.

  • If \(f(u,\theta)\) is (along with being differentiable in both variables) strictly convex in \(u\) for any fixed \(\theta\), and the set \(\mathcal{U}\) is convex and compact, then \(F^*(\theta) = \min_{u \in \mathcal{U}} f(u,\theta)\) is differentiable for all \(\theta\), since the minimizer is unique.

  • The specific application of this theorem in robotics will become clear soon.

CONVEX ANALYSIS BASICS

HALF SQUARED DISTANCE AND PROJECTION


  • Given a closed set \(\mathcal{U}\), the point-to-set half-squared distance (P2S-HSD) \(E_{\mathcal{U}}(p)\) between a point \(p\) and \(\mathcal{U}\) is the half-squared Euclidean distance between \(p\) and its closest point in the set \(\mathcal{U}\).

  • This can be formulated as the optimization problem: $$E_{\mathcal{U}}(p) = \min_{u \in \mathcal{U}} 0.5 \|u-p\|^2;$$

  • Working with the P2S-HSD is often more convenient than working directly with the Euclidean distance.

CONVEX ANALYSIS BASICS

HALF SQUARED DISTANCE AND PROJECTION


  • This problem is convex if \(\mathcal{U}\) is convex. Furthermore, since the function \(f(u,p) = 0.5\|u-p\|^2\) is strictly convex in \(u\) for any fixed \(p\), the solution is unique. In this case, we define the projection operator \(\Pi_{\mathcal{U}}(p)\) as this unique minimizer.

  • Obviously, both the P2S-HSD and the projection are coordinate-dependent: the point \(p\) must be described in a reference frame \(\mathcal{F}_0\).

CONVEX ANALYSIS BASICS

PROPERTIES OF HALF SQUARED DISTANCE AND PROJECTION


  • Prop 1: If \(\mathcal{U}\) is a convex set, \(E_{\mathcal{U}}(p)\) is a convex function. If \(\mathcal{U}\) is a strictly convex set, \(E_{\mathcal{U}}(p)\) is a strictly convex function.

  • Prop 2: the line from a point \(p\) and \(u = \Pi^{\mathcal{U}}(p)\) is normal to \(\mathcal{U}\) at point \(u \), if this normal is well defined (i.e., \(u\) does not belong to a corner);

  • Prop 3: if \(\mathcal{U}\) is a convex set and \(p \not \in \mathcal{U}\), the hyperplane that passes through the mid-point of this line and is orthogonal to it is a separating hyperplane between \(\mathcal{U}\) and \(p\).

  • Prop 4: as a direct application of the Envelope Theorem: $$\nabla E_{\mathcal{U}}(p) = p - \Pi_{\mathcal{U}}(p).$$

CONVEX ANALYSIS BASICS

PROJECTION: PARTICULAR CASE OF A BOX


  • Let's compute the P2S-HSD and projection for a 3D box in the canonical pose, that is, a box centered at \((0, 0, 0)\) with sides aligned with the axes of \(\mathcal{F}_0\). We assume it has lengths \(\ell_x, \ell_y, \ell_z\) along the \(x\), \(y\), and \(z\) axes, respectively.

  • Let \(p = (p_x \ p_y \ p_z)^\top \). The optimization problem is then: $$\min_{x,y,z} \ \frac{(x-p_x)^2}{2} + \frac{(y-p_y)^2}{2} + \frac{(z-p_z)^2}{2} \quad \text{subject to} $$ $$ -\frac{\ell_x}{2} \leq x \leq \frac{\ell_x}{2}, \quad -\frac{\ell_y}{2} \leq y \leq \frac{\ell_y}{2}, \quad -\frac{\ell_z}{2} \leq z \leq \frac{\ell_z}{2}$$

CONVEX ANALYSIS BASICS

PROJECTION: PARTICULAR CASE OF A BOX


  • Note that the problem is separable: the constraints and the objective function are independent for each variable. Therefore, we can solve for each variable separately. In general, we need to solve the following one-dimensional problem: $$\min_u \ \frac{(u-p)^2}{2} \ \mbox{such that} \ -\frac{\ell}{2} \leq u \leq \frac{\ell}{2};$$

  • This is an easy problem. SUPPORT FUNCTION


  • The support function of a set \(\mathcal{U} \subseteq \mathbb{R}^n\) is the function \(s_{\mathcal{U}} : \mathbb{R}^n \to \mathbb{R}\) defined as: $$s_{\mathcal{U}}(d) = \max_{u \in \mathcal{U}} d^\top u;$$
  • The set of maximizers (not necessarily unique) of this optimization problem for a given \(d\) is called the support set, denoted as \(\mathcal{S}_{\mathcal{U}}(d)\).

  • If \(\mathcal{U}\) is convex, this is a convex optimization problem (think about why... despite being a maximization problem), and the function \(s_{\mathcal{U}}\) is convex. The set \(\mathcal{S}_{\mathcal{U}}(d)\) is also convex.

TYPES OF DISTANCES


  • Knowing how close objects are is, of course, of paramount importance in robotics;

  • There are three "degrees" of distances we may care about:

    • Overlap oracles: given two objects, it just say if they overlap or not;

DISTANCES AND OTHER QUANTITIES

OVERLAP ORACLES


  • Some applications in robotics do not require knowing the exact distance—only whether objects overlap or not.

  • For example, the classic RRT (Rapidly-exploring Random Trees) algorithm for motion planning generates a collision-free path by sampling points in the configuration space and connecting them. This can be achieved using only a collision oracle \(c(q)\), which determines whether the robot, in a given configuration \(q\), overlaps with obstacles (or itself).

  • Different levels of safety can be implemented by enlarging the obstacles by a factor \(\epsilon\).

DISTANCES AND OTHER QUANTITIES

OVERLAP ORACLES


  • This approach can be significantly more efficient than computing exact distances.

  • For example, suppose we enclose two very complex (possibly non-convex) objects within bounding spheres. Checking whether the two spheres overlap is extremely fast. If they do not, we can confidently conclude that the original objects do not overlap. However, computing the exact Euclidean distance in such cases could be much more time-consuming.

  • In control applications, however, we often need more than just this binary information. A finer-grained measure of "closeness" (such as the Euclidean distance) is often required.

DISTANCES AND OTHER QUANTITIES

GJK ALGORITHM


  • The GJK Algorithm (named after its authors, Gilbert, Johnson, and Keerthi) is a classic and highly efficient algorithm for computing the distance between two sets.

  • Consider two convex sets \(\mathcal{A}\) and \(\mathcal{B}\). The key insight of the algorithm is the following: the distance between \(\mathcal{A}\) and \(\mathcal{B}\) is the same as the distance between \(\mathcal{C} = \mathcal{A} \ominus \mathcal{B}\) and the origin. This holds because: $$\min_{a \in \mathcal{A}, b \in \mathcal{B}} \frac{\|a-b\|^2}{2} = \min_{c \in \mathcal{C}} \frac{\|c\|^2}{2}$$ since any element of \(\mathcal{C}\) can be written as \(c = a-b\) for some \(a \in \mathcal{A}\) and \(b \in \mathcal{B}\).

  • Now, we want to compute the distance (or half squared distance) between a set \(\mathcal{A}\) which is a set of \(n\) discrete points \({a_i}\) and a solid convex object \(\mathcal{B}\).

  • One could simply implement: $$\Lambda_{\mathcal{A},\mathcal{B}} = \min_{i=1,...,n} E_{\mathcal{B}}(a_i)$$ which would take the computation of \(n\) P2S-HSD.

  • What if \(n\) is very large? Can we do better?

  • Yes, we can, using a Bounding Volume Hierarchy (BVH)!

DISTANCES AND OTHER QUANTITIES

BOUNDING VOLUME HIERARCHY

  • We start by building a BVH for the point cloud \(\mathcal{A}\). This is done by dividing the points \(\{a_i\}\) into two groups, then dividing each of those groups into two more groups (resulting in four total), and so on, until we reach individual points that cannot be split further. These subdivisions are organized into a binary tree.

  • For each of these groups, which corresponds to a node, we compute a Bounding Volume, which is a simple set that tightly encapsulates all the points in the group. A very popular choice is to use Axis-Aligned Bounding Boxes (AABBs), which are boxes aligned with the axes of the world frame. These AABBs are very easy to compute!

  • Once we finish building the BVH, we will see how to use it to compute distances to a set \(\mathcal{B}\).

DISTANCES AND OTHER QUANTITIES

BOUNDING VOLUME HIERARCHY

  • There are many strategies for performing this division. A very popular one is:

    • First divide using the x-coordinate, placing half of the points on each side;
    • Then divide using the y-coordinate in the same way;
    • Then divide using the z-coordinate in the same way;
    • Return to dividing using the x-coordinate, and continue cycling...

  • It is much easier to understand what is happening with a 2D example. In this case, we will cycle between splitting along the x-axis (left and right) and the y-axis (down and up).

  • Before the algorithm starts, we compute the AABB for the object \(\mathcal{B}\) (this is easy to do) and set \(\ell^* = \infty\).

  • We start from the root node and compute the distance \(d\) between \(\mathcal{B}\)'s AABB and the AABB of the node (this is trivial to compute).

  • We keep expanding nodes into their two children, computing the \(d\) for each of them. We decide the next node to expand based on the smallest value of \(d\) among unexpanded nodes.

  • When we reach a leaf node, the situation is special. In that case, we compute the distance between \(\mathcal{B}\) (not its AABB) and the point in the leaf, calling it \(\ell\). Every time we compute a new \(\ell\), we compare it with the current \(\ell^*\) and update \(\ell^*\) if the new value is smaller.

  • We do not need to expand nodes for which \(d \geq \ell^*\). In fact, all the childrens of a node are going to have values of \(d\) or \(\ell\) that are greater than or equal to their parent node. Thus, there is no way we can obtain something smaller than \(\ell^*\) by looking into these nodes.

  • The algorithm stops and returns the current value of \(\ell^*\) when there are no more nodes to explore.

  • If the objects \(\mathcal{A}\) and \(\mathcal{B}\) move, the S2S-HSD \(\Lambda_{\mathcal{A},\mathcal{B}}\) changes. In this case, it may be useful to compute the derivative.

  • In most of the applications in robotics, \(\mathcal{A}\) and \(\mathcal{B}\) move as rigid bodies. Thus, lets start assuming that they move in time as follows: given fixed convex sets \(\mathcal{A}_0\) and \(\mathcal{B}_0\) - which are the sets of points when \(\mathcal{A}\) and \(\mathcal{B}\) have their body frame aligned with world frame - the sets \(\mathcal{A}(t)\) and \(\mathcal{B}(t)\) are the application of the rigid transformations \((Q_{\mathcal{A}}(t),s_{\mathcal{A}}(t))\) and \((Q_{\mathcal{B}}(t),s_{\mathcal{B}}(t))\) to \(\mathcal{A}_0\) and \(\mathcal{B}_0\), respectively, in which \(t\) is time.

  • Thus, \(F: \mathbb{R} \mapsto \mathbb{R}\) defined as \(F(t) = \Lambda_{\mathcal{A}(t),\mathcal{B}(t)}\) can be defined, and we want to compute \(\frac{d}{dt}F(t)\).

  • This derivative will serve as a basis to compute more complex derivatives/gradients with respect to other variables.

  • We start by noting that: $$F(t) = \Lambda_{\mathcal{A}(t),\mathcal{B}(t)} = \min_{a \in \mathcal{A}(t), b \in \mathcal{B}(t)} = \frac{\|a-b\|^2}{2} = \min_{a_0 \in \mathcal{A}_0, b_0 \in \mathcal{B}_0} \underbrace{\frac{\|\big(Q_{\mathcal{A}}(t)a_0 + s_{\mathcal{A}}(t)\big) - \big(Q_{\mathcal{B}}(t)b_0 + s_{\mathcal{B}}(t)\big)\|^2}{2}}_{f(a_0,b_0,t)}$$

  • We are just writing the optimization problem using the local coordinates \(a_0\) and \(b_0\) (written in the objects' respective's body frames) instead of the original variables \(a,b\), that were written in the global (world) frame.

  • Now we can apply The Envelope Theorem since the constraints \(a_0 \in \mathcal{A}_0, b_0 \in \mathcal{B}_0\) are independent of the parameter \(t\). In this case: $$\frac{d}{dt} F(t) = \frac{\partial f}{\partial t}(a_0^*, b_0^*, t)$$ in which \(a_0^*(t),b_0^*(t)\) are the optimal \(a_0,b_0\) at a given \(t\).

Using the properties from differential kinematics, it can be shown that: $$\frac{\partial f}{\partial t}(a_0,b_0,t) = \Big((Q_{\mathcal{A}}a_0+s_{\mathcal{A}})-(Q_{\mathcal{B}}b_0+s_{\mathcal{B}})\Big)^\top\Big( \big(\omega_{\mathcal{A}} \times (Q_{\mathcal{A}}a_0)+v_{\mathcal{A}}\big) - \big(\omega_{\mathcal{B}} \times (Q_{\mathcal{B}}b_0)+v_{\mathcal{B}}\big) \Big) $$ in which the dependencies on \(t\) were omitted.

But note that \(Q_{\mathcal{A}}(t)a_0^*(t)+s_{\mathcal{A}}(t)\) is the closest point in \(\mathcal{A}(t)\) to \(\mathcal{B}(t)\), called \(a^*(t)\), and similarly, \(Q_{\mathcal{B}}(t)b_0^*(t)+s_{\mathcal{B}}(t)\) is the closest point in \(\mathcal{B}(t)\) to \(\mathcal{A}(t)\), that is, \(b^*(t)\)!

  • \(a_0^*(t)\) and \(b_0^*(t)\) were just the coordinates of \(a^*(t)\) and \(b^*(t)\), respectively, written in the respective body frame local coordinates instead of the global (world) coordinates, as \(a^*\) and \(b^*\) are.

The closest points \(a^*(t)\) and \(b^*(t)\) at a given time \(t\) can be computed by running any of the distance computation algorithms for \(\mathcal{A}(t)\) and \(\mathcal{B}(t)\).

  • Let \(\hat{\Lambda}_{\mathcal{A},\mathcal{B}}\) be a "new" measure of "half-squared distance" (a new S2S-HSD) between two objects \(\mathcal{A}\) and \(\mathcal{B}\). Which properties it should have?

  • To start with, those are reasonable intuitive properties:

    • (2) It should increase as the objects move away from each other.

  • In control, a class \(\mathcal{K}\) function (class "Kappa") is a function \(\kappa : \mathbb{R}^+ \mapsto \mathbb{R}^+\) (from nonnegative reals to nonnegative reals) that is continuous and strictly increasing, such that \(\kappa(0)=0\).

  • For example, \(\kappa(u) = 2u\), \(\kappa(u)=u^2\). Non-examples include \(\kappa(u) = \min(u,1)\) (it is increasing but not strictly increasing), and \(\kappa(u)=u+1\) (it does not satisfy \(\kappa(0) = 0\)).

  • Then, we can formally establish properties (1) and (2) by using the traditional S2S-HSD \(\Lambda_{\mathcal{A},\mathcal{B}}\) and our new measure \(\hat{\Lambda}_{\mathcal{A},\mathcal{B}}\). There should exist two class \(\mathcal{K}\) functions \(\kappa_{sup}\) and \(\kappa_{inf}\) such that: $$\kappa_{sup}(\Lambda_{\mathcal{A},\mathcal{B}}) \geq \hat{\Lambda}_{\mathcal{A},\mathcal{B}} \geq \kappa_{inf}(\Lambda_{\mathcal{A},\mathcal{B}}).$$

DIFFERENTIABLE DISTANCES

BEYOND EUCLIDEAN DISTANCE

  • Why?

  • For property (1), note that since \(\Lambda_{\mathcal{A},\mathcal{B}}\geq 0\) and \(\kappa_{inf}\) is a class \(\mathcal{K}\) function, then \(\hat{\Lambda}_{\mathcal{A},\mathcal{B}} \geq \kappa_{inf}(\Lambda_{\mathcal{A},\mathcal{B}})\geq 0\). Furthermore:

    • \(\mathcal{A}\) and \(\mathcal{B}\) overlap \(\rightarrow\) \(\hat{\Lambda}_{\mathcal{A},\mathcal{B}} = 0\): If the objects overlap, \(\Lambda_{\mathcal{A},\mathcal{B}}=0\), and thus, since \(\kappa_{inf}(0)=\kappa_{sup}(0)=0\), we have \(\hat{\Lambda}_{\mathcal{A},\mathcal{B}} = 0\).

    • \(\hat{\Lambda}_{\mathcal{A},\mathcal{B}} = 0\) \(\rightarrow\) \(\mathcal{A}\) and \(\mathcal{B}\) overlap: If \(\hat{\Lambda}_{\mathcal{A},\mathcal{B}} = 0\), then \(0 \geq \kappa_{inf}(\Lambda_{\mathcal{A},\mathcal{B}})\). Hence, due to the properties of class \(\mathcal{K}\) functions, we have \(\Lambda_{\mathcal{A},\mathcal{B}}=0\), which implies that the objects overlap.

  • For property (2), we simply use \(\hat{\Lambda}_{\mathcal{A},\mathcal{B}} \geq \kappa_{inf}(\Lambda_{\mathcal{A},\mathcal{B}})\), and recall that \(\kappa_{inf}\) is strictly increasing and that the Euclidean S2S-HSD \(\Lambda_{\mathcal{A},\mathcal{B}}\) has the property of increasing as the objects move away from each other.

  • Consider a convex set \(\mathcal{S}\). Lets examine some properties of the Euclidean P2S-HSD \(E_{\mathcal{S}}(p)\):

DIFFERENTIABLE DISTANCES

GONÇALVES' P2S-HSD

  • Consider a convex set \(\mathcal{S}\). A Gonçalves P2S-HSD for this set \(\mathcal{S}\) \(\hat{E}_{\mathcal{S}}(p)\) is any (there are infinitely many choices!) function \(\hat{E}_{\mathcal{S}} : \mathbb{R}^n \mapsto \mathbb{R}^+\) such that

    • (0) : \(\hat{E}_{\mathcal{S}}(p)\) is twice differentiable in \(p\);

    • (1) : \(\hat{E}_{\mathcal{S}}(p) \geq 0\) and \(\hat{E}_{\mathcal{S}}(p) = 0\) if and only if \(p\in\mathcal{S}\);

    • (2) : \(\frac{\partial^2 E_{\mathcal{S}}}{\partial p^2}(p) > 0_{n \times n}\) for any \(p \not \in \mathcal{S}\);

    • (3) : \(I_{n \times n} > \frac{\partial^2 E_{\mathcal{S}}}{\partial p^2}(p)\).

  • The new conditions (2) and (3) are stronger versions of the previous conditions for the Euclidean case. In fact, the previous conditions can be written as \(\frac{\partial^2 E_{\mathcal{S}}}{\partial p^2}(p)\) \(\geq\) \(0_{n \times n}\) and \(I_{n \times n}\) \(\geq\) \(\frac{\partial^2 E_{\mathcal{S}}}{\partial p^2}(p)\) (note the \(\geq\) instead of \(>\)) at the points \(p\) where the function is twice differentiable.

  • One simple example is as follows, for any positive scalar \(h\): $$ \Phi(s) = \left\{ \begin{array}{ll} \frac{s^3}{2(s+h)} & \mbox{if } s \geq 0 \\ 0 & \mbox{if } s < 0 \end{array} \right. $$

COMPUTING GONÇALVES' P2S-HSD

  • Consider a ball centered at the point \(p_c\) with radius \(R\) that strictly covers the set \(\mathcal{S}\) (i.e., any point of \(\mathcal{S}\) is contained inside the ball, but not in its borders).

  • Let \(\rho(p) = 0.5(\|p-p_c\|^2-R^2) \). It can be shown that for a sufficiently small but positive \(\epsilon\): $$ \hat{E}_{\mathcal{S}}(p) = \epsilon \rho(p) +\sqrt{\epsilon^2 \rho(p)^2 + (1-2\epsilon)\hat{e}_{\mathcal{S}}(p)^2 }$$ is a Gonçalves' P2S-HSD.

  • This is called the bulging procedure because if one compares the non-zero level sets of \(\hat{e}_{\mathcal{S}}\) and \(\hat{E}_{\mathcal{S}}\) for a convex set \(\mathcal{S}\) with flat sides (e.g., a square), the former's level sets have flat sides, whereas the latter's bulge slightly, making them curved.

DIFFERENTIABLE DISTANCES

GONÇALVES' PROJECTION

  • Remember that there is a theorem that relates the Euclidean P2S-HSD and the Euclidean projection: $$\Pi_{\mathcal{S}}(p) = p - \nabla E_{\mathcal{S}}(p).$$

  • By analogy, we define the Gonçalves' projection for the set \(\mathcal{S}\) as: $$\hat{\Pi}_{\mathcal{S}}(p) = p - \nabla \hat{E}_{\mathcal{S}}(p).$$

  • Note that Gonçalves' projection does not come from an optimization problem, it simply comes from a mathematical definition.

  • Gonçalves' P2S-HSD and projections will be useful for our two next algorithms.

DIFFERENTIABLE DISTANCES

GONÇALVES' ALTERNATING PROJECTION

  • We can use exactly the same algorithm as Von Neumann's alternating projection but using Gonçalves's projections instead of Euclidean projections! $$b[k] = \hat{\Pi}_{\mathcal{A}}(a[k])$$ $$a[k+1] = \hat{\Pi}_{\mathcal{B}}(b[k])$$

  • If both sets are convex, this algorithm will converge to points \(a^*,b^*\), called Gonçalves's witness points. Furthermore, if the sets do not overlap, this pair is unique (regardless if the sets are strictly convex or not).

  • How do we use these witness points to compute \(\hat{\Lambda}_{\mathcal{A},\mathcal{B}}\)?

DIFFERENTIABLE DISTANCES

GONÇALVES' ALTERNATING PROJECTION

  • One could expect that we would simply use: $$ \hat{\Lambda}_{\mathcal{A},\mathcal{B}} = \frac{\|a^*-b^*\|^2}{2}.$$

  • However, we could do better than this. It is better to use: $$ \hat{\Lambda}_{\mathcal{A},\mathcal{B}} = E_{\mathcal{A}}(b^*)+E_{\mathcal{B}}(a^*)-\frac{\|a^*-b^*\|^2}{2}.$$

  • Why this "bizarre" formula? It comes from Game theory!

  • Among some of the benefits of this formula, the formula for derivative of the distance that we obtained some slides ago is still valid, just by changing traditional witness points by Gonçalves' (this would not hold true if we used the simpler definition of \(\hat{\Lambda}_{\mathcal{A},\mathcal{B}}\)).

GONÇALVES' ALTERNATING PROJECTION

  • The parameters \(h\) and \(\epsilon\) control the smoothness of the S2S-HSD. The larger they are, the smoother is the distance, but the further away it is from the Euclidean distance.

  • The algorithm suffers from the slow performance of the original Von Neumman's method.

  • But it is much simpler to implement for general polytopes and the distance is differentiable!

  • Theoretically there are ways to accelerate the convergence (e.g., Anderson Acceleration), but I was not able to make it work...

  • Finally, it can be shown that the functions \(\kappa_{inf}\) and \(\kappa_{sup}\) exist, but it is not trivial to compute them.

DIFFERENTIABLE DISTANCES

SHORT-CIRCUIT ALGORITHM

  • What if we want to compute the distance between a pointcloud \(\mathcal{A}\) and a convex set \(\mathcal{B}\) that is differentiable?

  • Remember that, for the true Euclidean S2S-HSD: $$\Lambda_{\mathcal{A},\mathcal{B}} = \min_{i=1,...,N} E_{\mathcal{B}}(a_i).$$

  • This formula is not differentiable for two reasons. First, because \(E_{\mathcal{B}}(a_i)\) isnt. Second, because the minimum is not differentiable when there are more than one index \(i\) that achieves the minimum.

  • The first source of non-differentiability can be solved by using Gonçalves's S2S-HSD \(\hat{E}_{\mathcal{B}}(a_i)\) instead of \(E_{\mathcal{B}}(a_i)\).

DIFFERENTIABLE DISTANCES

SHORT-CIRCUIT ALGORITHM

  • For the second one, we use the Short-circuit algorithm that approximates the minimum with a differentiable expression.

  • It goes as follows. Suppose we have nonnegative numbers \(D_i\). Simply choose a \(r>0\) and compute: $$\hat{D}_{r,min} = \left(\sum_{i=1}^N D_i^{-1/r} \right)^{-r}.$$

  • Note that if at least one of the \(D_i\) is zero, \(\hat{D}_{r,min} = 0\), and it is otherwise positive.

  • The name comes from the fact that the formula resembles the formula for parallel resistances in electrical circuits (choose \(r=1\) and interpret \(D_i\) as resistances). The aforementioned behavior of zeroing the function then resembles the behavior of short-circuit (when one of the resistances are zero).

DIFFERENTIABLE DISTANCES

SHORT-CIRCUIT ALGORITHM

  • One word of caution, though. This formula, as presented, is numerically unstable. It is unsuitable to be implemented in a finite-precision machine (as any computer is). This can be easily solved by rewritting the short-circuit expression as follows. Let \(D_{min}= \min_{i=1,...,N} D_i\) be the true minimum. The, it can be shown that: $$\hat{D}_{r,min} = D_{min} \left(\sum_{i=1}^N (D_i/D_{min})^{-1/r} \right)^{-r}$$ and this is much more stable numerically.

  • Nevertheless, it can be shown that if \(r \rightarrow +0\), this approximation of the minimum recovers exactly the traditional minimum. Furthermore, for any \(r>0\), this approximation is differentiable as long as the \(D_i\) are differentiable.

DIFFERENTIABLE DISTANCES

SHORT-CIRCUIT ALGORITHM

  • Thus, we can simply choose a \(r>0\) and use: $$\hat{\Lambda}_{\mathcal{A},\mathcal{B}} = \left(\sum_{i=1}^N \hat{E}_{\mathcal{B}}(a_i)^{-1/r} \right)^{-r}$$ for any Gonçalves' S2S-HSD function \(\hat{E}_{\mathcal{B}}\) for the set \(\mathcal{B}\).

  • This expression is differentiable, but we cannot use the formula from the previous slides . It is not difficult to find one for the derivative, though (it is a nice Calculus exercise).

DIFFERENTIABLE DISTANCES

SHORT-CIRCUIT ALGORITHM

  • This can be much less efficient to compute than the Euclidean S2S-HSD \(\Lambda_{\mathcal{A},\mathcal{B}}\) with Bounding Volume Hierarchy, though, since you have to evaluate all the \(\hat{E}_{\mathcal{B}}\).

  • However, even then BVHs can help. Note that points \(a_i\) that have $$\alpha_i = \hat{E}_{\mathcal{B}}(a_i)/\Lambda_{\mathcal{A},\mathcal{B}}$$ (the ratio between the i-th Gonçalves S2S-HSD and the Euclidean S2S-HSD) much greater than one do not contribute much in the short-circuit operation.

  • Thus, if we approximate \(\hat{E}_{\mathcal{B}}(a_i) \approx E_{\mathcal{B}}(a_i)\), then \(\alpha_i \approx E_{\mathcal{B}}(a_i)/\Lambda_{\mathcal{A},\mathcal{B}}\). We can use BVH's to efficiently detect points with large values of \(\alpha_i\) and take them out of the computation. UAIBot implements this optimization heuristic.

UAIBOT'S IMPLEMENTATION

  • UAIBot implements all these algorithms in the function compute_dist: 
    
import uaibot as ub

# Create some objects

cvx1 = ub.Box(htm=ub.Utils.trn([1, 0, 0]), width=0.1, depth=0.2, height=0.3)
cvx2 = ub.Ball(htm=ub.Utils.trn([-1, 0, 0]), radius=0.1)
pc1 = ub.PointCloud(points=[[-1, 0, 0.2], [-1, 0, -0.2], [-1, 0, 0]])
pc2 = ub.PointCloud(points=[[1, 0, 0.2], [1, 0, -0.2], [1, 0, 0]])

# When compute_dist is called between two solid objects, it uses GJK.
# It returns the witness points (pointA, pointB), the distance
# (not the squared distance!), and some debugging information as the last output.

pointA, pointB, dist, _ = cvx1.compute_dist(cvx2)

# When compute_dist is called between a solid object and a point cloud, it uses BVH.
# It returns the witness points (pointA, pointB), the distance
# (not the squared distance!), and some debugging information as the last output.

pointA, pointB, dist, _ = pc1.compute_dist(cvx1)

# When compute_dist is called between two solid objects with nonzero h and eps,
# it uses Gonçalves' Alternating Projection method.
# It returns the Gonçalves' witness points (pointA, pointB), the Gonçalves distance
# (i.e., sqrt(2*Lambda)), and some debugging information.

pointA, pointB, dist, _ = cvx1.compute_dist(cvx2, h=0.1, eps=0.05)

# When compute_dist is called between a solid object and a point cloud with nonzero
# h and eps, it uses the Short-Circuit algorithm.
# It returns the Gonçalves' witness points (pointA, pointB), the distance
# (i.e., sqrt(2*Lambda)), and some debugging information.

pointA, pointB, dist, _ = pc1.compute_dist(cvx1, h=0.1, eps=0.05)

# If compute_dist is called between two point clouds, it raises an error!

pointA, pointB, dist, _ = pc1.compute_dist(pc2)
pointA, pointB, dist, _ = pc1.compute_dist(pc2, h=0.1, eps=0.05)
