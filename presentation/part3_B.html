CASE STUDIES

EXAMPLE 1: A MANIPULATOR WORKING IN A FACTORY

  • In this example, we have a Kuka LBR IIWA manipulator that needs to pick up an object (a disk) from a table, place it inside a machine that will test the object, press a button to start the machine, retrieve the object from the machine, and place it back on a table in a different location.

  • We assume that we control the joint velocity, i.e., \(\dot{q} = u\).

  • We have several constraints in this case:


    • Joint limits;
    • Joint velocity limits;
    • Obstacle avoidance.

CASE STUDIES

EXAMPLE 1: JOINT LIMITS

  • Suppose we have joint limits \(\underline{q}_i\) (lower) and \(\overline{q}_i\) (upper). We can simply use the CBF functions: $$B_{i}^{JL}(q) = q_i - \underline{q}_i;$$ $$B_{i}^{JU}(q) = \overline{q}_i - q_i.$$

  • The Jacobians are trivial to compute:
    $$B_{i}^{JL}(q) = q_i - \underline{q}_i$$ $$\frac{\partial B_{i}^{JL}}{\partial q}(q) = e_i^{\top};$$ $$\frac{\partial B_{i}^{JU}}{\partial q}(q) = -e_i^{\top}$$ where \(e_i\) is the \(i^{th}\) column of the \(n \times n\) identity matrix.

CASE STUDIES

EXAMPLE 1: JOINT VELOCITY LIMITS

  • Suppose we have joint velocity limits \(\underline{u}_i\) (lower) and \(\overline{u}_i\) (upper). We can trivially implement these constraints directly (without the need to use any CBF): $$u_i \geq \underline{u}_i$$ $$u_i \leq \overline{u}_i \ \rightarrow \ -u_i \geq -\overline{u}_i.$$

CASE STUDIES

EXAMPLE 1: OBSTACLE AVOIDANCE

  • For obstacle avoidance, we consider that the robot is composed of \(r = 1, \dots, R\) objects (spheres, boxes, etc...), and that the static environment is composed of \(w = 1, \dots, W\) objects. For each pair, we compute the Euclidean distance between the \(r^{th}\) robot object's at configuration \(q\), \(\mathcal{R}(r, q) \subseteq \mathbb{R}^3\), and the \(w^{th}\) environment object \(\mathcal{O}(w) \subseteq \mathbb{R}^3\): $$ D^{RO}_{rw}(q) = \sqrt{2\Lambda_{\mathcal{R}(r,q), \mathcal{O}(w)}}.$$

  • Remember that \(\Lambda\) is the set-to-set half squared distance (hence the \(\sqrt{2\Lambda}\) to recover the distance).

  • We can then simply set: $$B^{RO}_{rw}(q) = D^{RO}_{rw}(q) - \delta$$ where \(\delta\) is a safety margin.

CASE STUDIES

EXAMPLE 1: OBSTACLE AVOIDANCE

  • Can we use the half-squared distance directly? Yes, but although HSD is more convenient theoretically and computationally, in my experience, using the distance is better when implementing safety.

  • We can compute the Jacobian of these functions using the distance Jacobian for the S2S-HSD that we learned to compute , since, from the chain rule: $$ \frac{\partial}{\partial q} B^{RO}_{rw}(q) = \frac{1}{D^{RO}_{rw}(q)} \frac{\partial }{\partial q} \Lambda_{\mathcal{R}(r,q), \mathcal{O}(w)}.$$

  • UAIBot's compute_dist already computes the Euclidean distance and the Euclidean distance Jacobian, thus already implementing this equation.

CASE STUDIES

EXAMPLE 1: OBSTACLE AVOIDANCE

  • We need to be careful, because once the robot picks up the object, we also need to implement a constraint that avoids collisions between the disk, being held by the end-effector, and the environment.

  • When the disk is being held, the space it occupies is represented by a set \(\mathcal{D}(q)\) that moves rigidly in space. Thus, we can create a CBF constraint for it as well: $$ B^{DO}_{w}(q) = D^{DO}_{w}(q) - \delta = \sqrt{2 \Lambda_{\mathcal{D}(q), \mathcal{O}(w)}} - \delta$$ and we need to implement one constraint for each object \(w\) in the environment.

CASE STUDIES

EXAMPLE 1: OBJECTIVE FUNCTION

  • We will use our classical task function \(r(q)\) to achieve a target pose \(H_{tg}\) pose as the objective function of our QP: $$ \min_u \left\|\frac{\partial r}{\partial q}(q)u - G(r(q))\right\|^2 + \epsilon \|u\|^2$$ for a regularization parameter \(\epsilon\).

  • \(G\) is the function described here;

  • This target pose \(H_{tg}\) will change discretely as we switch between different modes of operation.

  • Thus, we will try our luck without path planning, but we will implement the anti-stuck policy mentioned previously.

EXAMPLE 1: FINAL FORMULATION

$$\min_{u} \ \ \left\|\frac{\partial r}{\partial q}(q)+Kr(q)\right\|^2 + \epsilon \|u\|^2 \ \ \mbox{subject to}$$ Joint limits: $$u_i \geq -\eta(q_i - \underline{q}_i) \ , \ i=1,..,N$$ $$-u_i \geq -\eta(\overline{q}_i - q_i) \ , \ i=1,..,N$$ Velocity limits: $$u_i \geq \underline{u}_i \ , \ i=1,..,n$$ $$-u_i \geq -\overline{u}_i \ , \ i=1,..,n$$ Collision avoidance between robot and environment: $$\frac{\partial B^{RO}_{rw}}{\partial q}(q)u \geq -\eta B^{RO}_{rw}(q) \ , \ r=1,..,R; w = 1,...,W$$ Collision avoidance between disk and environment (only when holding disk): $$\frac{\partial B^{DO}_{w}}{\partial q}(q)u \geq -\eta B^{DO}_{w}(q) \ , \ w = 1,...,W$$

EXAMPLE 1: MODES OF OPERATION

  • Our task has some discrete states ("Modes"). In each of them, we will have different target poses \(H_{tg}\).

  • In some cases, when we grab the disk, we have to disable collision avoidance. This is because we need to get extremely close to an obstacle. This is not a problem because it will be a very subtle and controlled movement.

  • In other cases, we need to enable collision avoidance with the object (disk), implementing the CBF functions \(B^{DO}_{w}(q)\) that we have already seen.

def fun_G(_r, _param_k):
    m = np.shape(_r)[0]
    out = np.matrix(np.zeros((m,1)))
    for i in range(m):
        out[i,0] = -_param_k * np.sign(_r[i,0]) * np.sqrt(np.abs(_r[i,0]))
       
    return out

def control_fun(_q, _htm_tg, _all_obstacles, _is_handling_disk, _care_obstacles, _perturbation):
    
    no_joint = np.shape(robot.q)[0]
    
    A = np.matrix(np.zeros((0,no_joint)))
    b = np.matrix(np.zeros((0,1)))
    
    #### CONSTRAINT 1: COLLISION BETWEEN THE MANIPULATOR AND OBSTACLES ####
    
    #Create the CBF constraints for all obstacles:
    if _care_obstacles:
        
        #Between the robot and the objects
        for obs in _all_obstacles:
            ds = robot.compute_dist(q = _q, obj = obs)
            A = np.vstack((A, ds.jac_dist_mat))
            b = np.vstack((b, -param_eta*(ds.dist_vect-param_obs_delta)) )
        
        #If the disk is in the end-effector, it should also be handled
        if _is_handling_disk:

            #Call the forward kinematic and differential for the end-effector,
            #since this is where the disk is attaches
            jac, htm = robot.jac_geo(q=_q)
            
            s_e = htm[0:3,-1]
            jac_v = jac[0:3,:]
            jac_w = jac[3:6,:]
            
            for obs in _all_obstacles:
                point_disk, point_obs, dist, _ = disk.compute_dist(obs)
                
                #print(dist)

                jac_dist = ((point_disk - point_obs).T * jac_v + np.cross((point_disk - s_e ).T, (point_disk - point_obs).T)  * jac_w)/dist
                A = np.vstack((A, jac_dist))
                b = np.vstack((b, -param_eta*(dist-param_obs_delta)))
        
    #### CONSTRAINT 2: JOINT LIMITS ####
                
    #Create the CBF constraint for joint limits
    A = np.vstack((A, np.identity(no_joint)))
    b = np.vstack((b, -param_eta*(_q-robot.joint_limit[:,0]-param_joint_delta) ))  
    A = np.vstack((A, -np.identity(no_joint)))
    b = np.vstack((b, -param_eta*(robot.joint_limit[:,1]-_q-param_joint_delta) ))  
    
    #### CONSTRAINT 3: VELOCITY LIMITS ####
    
    #Implement velocity limits
    A = np.vstack((A, np.identity(no_joint)))
    b = np.vstack((b, -param_max_dotq*np.matrix(np.ones((no_joint,1))) ))  
    A = np.vstack((A, -np.identity(no_joint)))
    b = np.vstack((b, -param_max_dotq*np.matrix(np.ones((no_joint,1))) ))      
    
    
    #Create the objective function
    r, jac_r = robot.task_function(q=_q, htm_tg=_htm_tg)
        
    H = 2*(jac_r.T * jac_r + param_eps* np.identity(no_joint))
    f = -2*jac_r.T*fun_G(r, param_k)+_perturbation
    
    #Compute the control input
    u = ub.Utils.solve_qp(H, f, A, b)

    return u, np.linalg.norm(r)

q = np.matrix(robot.q)
no_joint = np.shape(q)[0]

mode = 0
cont = True
i=0

hist_q = []
hist_u = []
hist_t = []
hist_e = []

perturbation = np.matrix(np.zeros((no_joint,1)))
perturbation_mode = False
while cont:
    
    i+=1
    cont = i < param_iter_max
    

    u, error_r = control_fun(q, htm_tg[mode], all_obstacles, is_handling_disk[mode], care_obstacles[mode], perturbation)
    
    print("Mode "+str(mode)+", error = "+str(round(error_r,3)))
    
    if cont and error_r<=param_tol_error:
        
        mode += 1
        
        if mode==len(htm_tg):
            cont = False
        else:
            if mode > 0 and not is_handling_disk[mode-1] and is_handling_disk[mode]:
                robot.attach_object(disk)

            if mode > 0 and is_handling_disk[mode-1] and not is_handling_disk[mode]:
                robot.detach_object(disk)

    #Integrate movement
    q = robot.q+u*dt
    robot.add_ani_frame(time = i*dt, q = q)
                       
    #Store data

    hist_u.append(np.matrix(u))
    hist_t.append(i*dt)
    hist_e.append(error_r)
    
    #Make the perturbation to avoid getting stuck
    if i>param_iter_check_convergence and not perturbation_mode:
        recent = hist_e[-param_iter_check_convergence:]
        max_diff = (max(recent) - min(recent))/max(recent)
        if max_diff < param_min_diff_error:
            perturbation = np.matrix(np.random.randn(no_joint,1))
            perturbation_mode = True
            print("CONVERGENCE FAILED")
    
    if perturbation_mode:
        perturbation = param_decay_convergence*perturbation
        if np.linalg.norm(perturbation)<=param_min_perturbation:
            perturbation = np.matrix(np.zeros((no_joint,1)))
            perturbation_mode = False
