CASE STUDIES

EXAMPLE 3: MULTIPLE AGENTS

  • We now have \(N\) flying mobile robots (drones) moving in 3D space within an environment modeled as a point cloud.

  • They should reach designated target points while avoiding collisions with the environment and with each other.

  • Let \(p_i \in \mathbb{R}^3\) denote the 3D position of the \(i^{th}\) agent. The system configuration \(q \in \mathbb{R}^{3N}\) is the stacked vector of all agent positions.

  • We assume that we control each agent's 3D acceleration. From the configuration's point of view, the system dynamics is \(\ddot{q} = u\).

CASE STUDIES

EXAMPLE 3: CENTRALIZED VS DECENTRALIZED

  • In this case, where we have a multi-agent system (e.g., many robots), there is an important distinction between a centralized and a decentralized approach.

  • In the centralized approach, all robots communicate with a central computer, which processes everything and then sends the control inputs back to each agent.

  • In the decentralized approach, robots communicate only locally (with neighboring agents, using sensors) and each agent decides its control input individually based on this information.

  • The latter is more practical because the former requires communication infrastructure that is not always available. However, assuming it is feasible, the former is easier to implement.

  • Here, we will assume a centralized approach.

CASE STUDIES

EXAMPLE 3: CONSTRAINTS

  • We have the following constraints:

    • Input (acceleration) limits for the agents;

    • Speed limits for the agents;

    • Obstacle avoidance between the agents;

    • Obstacle avoidance between the agent and the environment;

CASE STUDIES

EXAMPLE 3: INPUT AND SPEED LIMITS

  • Inputs limits are easy to implement: $$ \underline{u}_i \leq u_i \leq \overline{u}_i $$

  • For velocity limits, we use the CBFs \(B_i^{LS}(q,\dot{q}) = \dot{q}_i-\underline{v}_i\) and \(B_i^{US}(q,\dot{q}) = \overline{v}_i-\dot{q}_i\) : $$\frac{d}{dt} B_i^{LS}(q,\dot{q}) \geq -\eta B_i^{LS}(q,\dot{q}) \ \rightarrow \ u_i \geq -\eta( \dot{q}_i-\underline{v}_i);$$ $$\frac{d}{dt} B_i^{US}(q,\dot{q}) \geq -\eta B_i^{US}(q,\dot{q}) \ \rightarrow \ -u_i \geq -\eta( \overline{v}_i-\dot{q}_i);$$

CASE STUDIES

EXAMPLE 3: INTER-AGENT COLLISION

  • For collision, we model all the robots with spheres of radius \(R\).

  • For inter-agent collision, we consider robots \(i=1,...,N\) and for each pair \(i=1,...,N\), \(j=i+1,...,N\), we have the CBF: $$B_{ij}^{RR}(q) = \|p_i-p_j\| -2R.$$

  • The Jacobian is given by a \(1 \times 3N\) vector such that the entry for \(k=i,i+1,i+2\) is $$(p_i-p_j)^{\top}/\|p_i-p_j\|$$ and for \(k=j,j+1,j+2\) we have $$-(p_i-p_j)^{\top}/\|p_i-p_j\|$$ and \(0\) for all other \(k\).

CASE STUDIES

EXAMPLE 3: INTER-AGENT COLLISION

  • The Hessian can be computed analytically with relative ease. But we will use the trick explained here : $$\dot{q}^{\top} \frac{\partial^2 B_{ij}^{RR}}{\partial q^2}(q)\dot{q} \approx \left( \frac{\partial B_{ij}^{RR}}{\partial q}(q{+}\Delta t \dot{q}) {-} \frac{\partial B_{ij}^{RR}}{\partial q}(q{-}\Delta t \dot{q}) \right)\frac{\dot{q}}{2\Delta t}.$$

  • We can then implement the constraint, as explained here: $$\frac{\partial B_{ij}^{RR}}{\partial q}(q)u \geq -2\eta \underbrace{\frac{\partial B_{ij}^{RR}}{\partial q}(q)\dot{q}}_{\dot{B}_{ij}^{RR}} - \eta^2 B_{ij}^{RR}(q)-\dot{q}^{\top} \frac{\partial^2 B_{ij}^{RR}}{\partial q^2}(q) \dot{q}.$$

CASE STUDIES

EXAMPLE 3: COLLISION WITH THE ENVIRONMENT

  • For collision avoidance between the static environment, modeled as a point cloud, and the agents, we can again use the Euclidean distance between each agent's sphere and the point cloud: $$B^{RO}_i(q) = D_i^{RO}(q)-\delta.$$

  • However, we will need the second-order term \(\dot{q}^{\top}\frac{\partial^2 B^{RO}_i(q)}{\partial q^2}\dot{q}\). But, as discussed before, for point clouds, \(D_i^{RO}\) (and thus \(B^{RO}_i\)) has a discontinuous first derivative when dealing with discrete point clouds, and therefore the second derivative will sometimes blow up.

  • This can cause discontinuities in the control input and even render the CBF constraint unfeasible, as it could require an acceleration so high that it violates our acceleration limits.

  • That’s where differentiable distances (especially the short-circuit algorithm) can help!

CASE STUDIES

EXAMPLE 3: COLLISION WITH THE ENVIRONMENT

  • So, let's assume \(D^{RO}_i(q)\) is computed as follows: we apply the short-circuit algorithm to all the Goncalves P2S-HSD distances between agent \(i\)'s sphere \(\mathcal{B}(q,i)\) and each of the \(n\) obstacle points \(o_k\), namely \(\hat{E}_{\mathcal{B}(q,i)}(o_k)\). What we get in the end is a differentiable half-squared distance. To recover the distance, we multiply by two and take the square root, obtaining: $$D^{RO}_i(q) = \sqrt{2\left( \sum_{k=1}^n \hat{E}_{\mathcal{B}(q,i)}(o_k)^{-1/r} \right)^{-r}}$$ where \(r\) is a smoothing parameter.

  • UAIBot's function compute_dist between a Ball and a Point Cloud with parameter \(h\) and \(\epsilon\) will compute this: 
    
import numpy as np
import uaibot as ub

#Create a point cloud with 3 points

#Compute differentiable distances and the respective witness points

  • In this case, \(r=h\), and \(h\) and \(\epsilon\) are parameters necessary to compute the Gonçalves P2S-HSD, as as seen here.

CASE STUDIES

EXAMPLE 3: COLLISION WITH THE ENVIRONMENT

  • The aforementioned UAIBot function will return two 3D witness points: one for the ball, \(p_i^*\), and another for the point cloud, \(o^*\). They are given by the following formulas: $$ p_i^* = \sum_{k=1}^n W_{ik} \hat{\Pi}_{\mathcal{B}(q,i)}(o_k),$$ $$ o_i^* = \sum_{k=1}^n W_{ik} o_k$$ where \(\hat{\Pi}_{\mathcal{B}(q,i)}(o_k)\) is Gonçalves' projection, and: $$W_{ik} = \frac{\hat{E}_{\mathcal{B}(q,i)}(o_k)^{-(1/r+1)}}{\left( \sum_{j=1}^n \hat{E}_{\mathcal{B}(q,i)}(o_j)^{-1/r} \right)^{1+r}}.$$

CASE STUDIES

EXAMPLE 3: COLLISION WITH THE ENVIRONMENT

  • As opposed to Gonçalves' S2S-HSD between two convex objects computed using the Alternating algorithm, we can’t, strictly speaking, use this formula for the derivative. However, it is a very good approximation, especially when \(r\) is small, as it usually is. Thus: $$\frac{\partial}{\partial p_i} B^{RO}_i(q) = \frac{\partial}{\partial p_i} D^{RO}_i(q) \approx \frac{1}{D^{RO}_i(q)}(p_i^*-o_i^*)^{\top}.$$ Here, we used the fact that the obstacle is static, the symmetry of the ball, and the fact that its frame is attached to its center (so there is no need to consider the angular velocity of the ball).

  • Note that the derivative is with respect to \(p_i\), which is part of the full configuration \(q\). However, computing \(\frac{\partial D^{RO}_i}{\partial q}\) from this is easy, as all other configurations except the three coordinates for agent \(i\) will have a zero partial derivative with respect to agent \(i\)'s obstacle avoidance with the environment.

CASE STUDIES

EXAMPLE 3: COLLISION WITH THE ENVIRONMENT

  • This time, the Hessian of \(B^{RO}_i(q)\) is much harder to compute (even for our approximation). As before, we will use the following trick: $$\dot{q}^{\top} \frac{\partial^2 B_{i}^{RO}}{\partial q^2}(q)\dot{q} \approx \left( \frac{\partial B_{i}^{RO}}{\partial q}(q{+}\Delta t \dot{q}) {-} \frac{\partial B_{i}^{RO}}{\partial q}(q{-}\Delta t \dot{q}) \right)\frac{\dot{q}}{2\Delta t}.$$
  • With this, we have everything we need to implement the obstacle avoidance constraint.

CASE STUDIES

EXAMPLE 3: OBJECTIVE FUNCTION

  • Each agent \(i\) will have its target point \(p_{d,i}\). We will see soon that these target points will be updated once the agent reaches it. Regardless, if we stack these vertically into a \((3N)\)-dimensional column vector \(q_{d}\), we can use the task function: $$r(q) = q - q_d$$ for which the Jacobian is simply the \((3N) \times (3N)\) identity matrix.

  • Thus, we can set the following objective function, as shown in this: $$\min_u \|u + 2K\dot{q} + K^2(q - q_d)\|^2$$ for a positive scalar \(K\).

  • There is no need for a regularization term \(\epsilon \|u\|^2\) because the Jacobian is already full rank.

CASE STUDIES

EXAMPLE 3: SIMPLE MOTION PLANNING

  • Simply setting \(p_{d,i}\) as the final target point for each agent most likely won’t work. The system will probably get stuck in an equilibrium point.

  • We can run a very crude motion planning algorithm that computes some intermediate points to help the agent reach the final target.

  • We will proceed as follows: for each agent, we will implement a simple probabilistic method that performs a random walk in the environment, checking if movement between points can be done with a straight line. Every once in a while, we attempt to connect the current point with the final target. Once successful, we run a simple algorithm to post-process the path and reduce the zig-zag behavior.

  • This algorithm will be used for each agent individually, considering only the static obstacles, without regard for the other agents. It is up to the CBF controller to handle inter-agent collision avoidance.

CASE STUDIES

EXAMPLE 3: FINAL FORMULATION

$$\min_{u} \ \ \|u+2K\dot{q}+K^2(q-q_{d})\|^2 \ \ \mbox{subject to}$$ Velocity and acceleration limits: $$u_i \geq \underline{u}_i \ , \ i=1,..,N$$ $$-u_i \geq -\overline{u}_i \ , \ i=1,..,N$$ $$u_i \geq -\eta(\dot{q}_i-\underline{v}_i) \ , \ i=1,..,N$$ $$-u_i \geq -\eta(\overline{v}_i-\dot{q}_i) \ , \ i=1,..,N$$ Inter-agent collision avoidance: $$\mbox{For} \ i=1,..,N \ , \ j=i+1,...,N:$$ $$\frac{\partial B_{ij}^{RR}(q)}{\partial q}u \geq -2\eta \frac{\partial B_{ij}^{RR}(q)}{\partial q}\dot{q} -\eta^2B_{ij}^{RR}(q) -\dot{q}^\top \frac{\partial^2 B_{ij}^{RR}(q)}{\partial q^2} \dot{q} $$ Agent-environment collision avoidance: $$\frac{\partial B_{i}^{RO}(q)}{\partial q}u \geq -2\eta \frac{\partial B_{i}^{RO}(q)}{\partial q}\dot{q} -\eta^2B_{i}^{RO}(q) -\dot{q}^\top \frac{\partial^2 B_{i}^{RO}(q)}{\partial q^2} \dot{q} \ , \ i=1,..,N$$

import numpy as np
import uaibot as ub


def check_free(_p, _pc, _radius, _bounds):
    
    if _p[0,0]< _bounds[0] or _p[0,0]>_bounds[1] or \
       _p[1,0]< _bounds[2] or _p[1,0]>_bounds[3] or \
       _p[2,0]< _bounds[4] or _p[2,0]>_bounds[5]:
           return False
    else:

        return _pc.projection(_p)[1]>1.2*_radius
    
def sample_random_direction(_p, _p_goal, _step_size):
    
    if np.random.uniform()<0.5:
        vec = np.random.randn(3)
        vec = vec/np.linalg.norm(vec)
        return _step_size* np.matrix(vec).T
    else:
        return _p_goal-_p

def is_line_free(_p1, _p2, _pc, _radius, _bounds):
    dist = np.linalg.norm(_p1-_p2)
    no_steps = int(dist/0.05)+1
    for i in range(no_steps):
        alpha = i/(no_steps-1+0.01)
        point = (1 - alpha) * _p1 + alpha * _p2
        if not check_free(point, _pc, _radius, _bounds):
            return False
    return True

def simplify_path(_path, _pc, _radius, _bounds):
    if len(_path) <= 2:
        return _path

    simplified = [_path[0]]
    i = 0
    while i < len(_path) - 1:
        j = len(_path) - 1
        while j > i + 1:
            if is_line_free(_path[i], _path[j], _pc, _radius, _bounds):
                break
            j -= 1
        simplified.append(_path[j])
        i = j

    return simplified

def random_path_planner(_p_start, _p_goal, _pc, _radius, _bounds,  _max_steps=16000, _step_size=0.5):
    path = [_p_start]
    current = _p_start.copy()

    found = False
    
    
    for i in range(_max_steps):
        direction = sample_random_direction(current, _p_goal, _step_size)
        new_point = current + direction 

        # Check line from current to new_point is free
        if not is_line_free(current, new_point, _pc, _radius, _bounds):
            continue

        path.append(new_point)
        
        current = new_point

        # Try to connect to goal if close enough
        if np.linalg.norm(_p_goal - current) < _step_size:
            if is_line_free(current, _p_goal, _pc, _radius, _bounds):
                path.append(_p_goal)
                found = True
                break

    if found:
        simpl_path = simplify_path(path, _pc, _radius, _bounds)
        print("Path found with "+str(len(simpl_path)-1))
        return simpl_path[1:]
    else:
        print("Path not found!")
        return [_p_goal]

def dfun(_q, _i, _j):
    
    qi = _q[3*_i:3*(_i+1),:]
    qj = _q[3*_j:3*(_j+1),:]
    
    return np.linalg.norm(qi-qj)-(2*param_radius)

def jac_dfun(_q, _i, _j):
    
    n = param_n_robots
    jac_dist = np.zeros((1,3*n))
    
    qi = _q[3*_i:3*(_i+1),:]
    qj = _q[3*_j:3*(_j+1),:]
    
    norm_ij = np.linalg.norm(qi-qj)
    
    jac_dist[0,3*_i:3*(_i+1)] = (qi-qj).T/norm_ij
    jac_dist[0,3*_j:3*(_j+1)] = (qj-qi).T/norm_ij
    
    return jac_dist

def dofun(_q, _i, _pc):
    qi = _q[3*_i:3*(_i+1),:]
    
    ball_i = ub.Ball(htm=ub.Utils.trn(qi), radius=param_radius)
    
    return ball_i.compute_dist(obj = _pc, h=param_h_dist, eps=param_eps_dist)[2]-param_delta

def dofun_real(_q, _i, _pc):

def control_fun(_q, _dotq, _all_tg, _pc):
    
    n = param_n_robots
    
    #Create the objective function
    H = 2*np.identity(3*n)
    f = np.zeros((3*n,1))
    
    error = 0
    
    for i in range(n):
        qi = _q[3*i:3*(i+1),:]
        dotqi = _dotq[3*i:3*(i+1),:]
        f[3*i:3*i+3,:] = ( 2*param_k*dotqi+ (param_k*param_k)*(qi-_all_tg[i]) )
        error+= np.linalg.norm(qi-_all_tg[i])
        
    f = 2*f
    
    
    #Create the constraints
    A = np.matrix(np.zeros((0,3*n)))
    b = np.matrix(np.zeros((0,1)))
    
    min_dist_agents = 1e6
    min_dist_obs = 1e6
    

    #Create the inter-agent collision constraints
    for i in range(n):
        for j in range(0,i):
            
            
            dist = dfun(_q, i, j)
            jac_dist = jac_dfun(_q, i, j)
            dist_dot = (dfun(_q+dt*_dotq, i, j)-dfun(_q-dt*_dotq, i, j))/(2*dt)
            dist_hess = ( (jac_dfun(_q+dt*_dotq, i, j)-jac_dfun(_q-dt*_dotq, i, j))/(2*dt))*_dotq

            
            #Implement extra safety
            dist_hess = min(dist_hess, 0)
            
            A = np.vstack((A, jac_dist))
            b = np.vstack((b, -2*param_eta*dist_dot - (param_eta*param_eta)*dist-dist_hess ) )
            
            min_dist_agents = min(dist, min_dist_agents)
            
    #Create the constraints with collisions with the environment
    for i in range(n):
            dist = dofun(_q, i, _pc)
            jac_dist = jac_dofun(_q, i, _pc)
            dist_dot = (dofun(_q+dt*_dotq, i, _pc)-dofun(_q-dt*_dotq, i, _pc))/(2*dt)
            dist_hess = ( (jac_dofun(_q+dt*_dotq, i, _pc)-jac_dofun(_q-dt*_dotq, i, _pc))/(2*dt))*_dotq
            
            #Implement extra safety
            dist_hess = min(dist_hess, 0)
            
            A = np.vstack((A, jac_dist))
            b = np.vstack((b, -2*param_eta*dist_dot - (param_eta*param_eta)*dist-dist_hess ) )
            
            min_dist_obs = min(dofun_real(_q, i, _pc), min_dist_obs)


    idm = np.identity(3*n)
    onev = np.ones((3*n,1))
                
    A =   np.vstack((A, idm, -idm)) 
    b =   np.vstack((b, -param_a_max*onev, -param_a_max*onev)) 
           
    A =   np.vstack((A, idm, -idm)) 
    b =   np.vstack((b, -2*param_eta_v*(_dotq+param_v_max*onev), -2*param_eta_v*(param_v_max*onev-_dotq) ))
    
    
    for i in range(n):
          jac_dist = np.zeros((1,3*n))
          jac_dist[0,3*i+2] = -1.0
          
          A =   np.vstack((A, jac_dist))
          b =   np.vstack((b, -2*param_eta*(-_dotq[3*i+2,-1])-(param_eta*param_eta)*( param_zmax+0.2 - _q[3*i+2,-1] ) )) 
          
          jac_dist[0,3*i+2] = 1.0
          
          A =   np.vstack((A, jac_dist))
          b =   np.vstack((b, -2*param_eta*(dotq[3*i+2,-1])-(param_eta*param_eta)*(_q[3*i+2,-1]-param_radius) )) 
      
    try:                 
        return ub.Utils.solve_qp(H,f,A,b), min_dist_agents, min_dist_obs
    except:
        #If it is not able to find a solution, brake for safety.
        norm_dotq = np.linalg.norm(_dotq)
        return -min(param_a_max,norm_dotq)*_dotq/(norm_dotq+1e-6), min_dist_agents, min_dist_obs
