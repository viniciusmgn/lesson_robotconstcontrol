CASE STUDIES

EXAMPLE 3: MULTIPLE AGENTS

  • Now, we have \(N\) flying mobile robots (drones) that move in the 3D space in an environment modelled by a point cloud.

  • They should go to designated target points while avoiding collisions with the environment and between themselves.

  • Let \(p_i \in \mathbb{R}^3\) be the 3D position of the \(i^{th}\) agent. The system's configuration \(q \in \mathbb{R}^{3N}\) is the stacked position of all agents.

  • We assume that we control each agent's 3D acceleration, so, from the point of view of configuration, the system dynamics is \(\ddot{q} = u\).

CASE STUDIES

EXAMPLE 3: CENTRALIZED VS DECENTRALIZED

  • In this case in which we have a multi-agent system (e.g., many robots), there is an important distinction between a centralized and decentralized approach.

  • In the centralized approach, all the robots communicate with a central computer, that processes everything and then send back to each agent the control input.

  • In the decentralized approach, all the robots communicate only locally (with neighbor agents, using sensors) and decide individually, based on this information, its control input.

  • The latter is more practical, because the former requires communication that we dont always have available. However, assuming that we can implement it, the former is easy to implement.

  • We will assume a centralized approach here.

CASE STUDIES

EXAMPLE 3: INPUT AND SPEED LIMITS

  • Inputs limits are easy to implement: $$ \underline{u}_i \leq u_i \leq \overline{u}_i $$

  • For velocity limits, we use the CBFs \(B_i^{LS}(q) = \dot{q}_i-\underline{v}_i\) and \(B_i^{US}(q) = \overline{v}_i-\dot{q}_i\) : $$\frac{d}{dt} B_i^{LS}(q) \geq -\eta B_i^{LS}(q) \ \rightarrow \ u_i \geq -\eta( \dot{q}_i-\underline{v}_i);$$ $$\frac{d}{dt} B_i^{US}(q) \geq -\eta B_i^{US}(q) \ \rightarrow \ -u_i \geq -\eta( \overline{v}_i-\dot{q}_i);$$

CASE STUDIES

EXAMPLE 3: INTER-AGENT COLLISION

  • For collision, we model all the robots with spheres of radius \(R\).

  • For inter-agent collision, we consider robots \(i=1,...,N\) and for each pair \(i=1,...,N\), \(j=i+1,...,N\), we have the CBF: $$B_{ij}^{RR}(q) = \|p_i-p_j\| -2R.$$

  • The Jacobian is given by a \(1 \times 3N\) vector such that the entry for \(k=i,i+1,i+2\) is $$(p_i-p_j)^{\top}/\|p_i-p_j\|$$ and for \(k=j,j+1,j+2\) we have $$-(p_i-p_j)^{\top}/\|p_i-p_j\|$$ and \(0\) for all other \(k\).
