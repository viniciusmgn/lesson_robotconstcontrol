PROBLEM 1


  • Given a circular path in the 3D space (that you can choose as you wish), we want the end-effector central point \(s\) to track it while staying in a constant orientation (that you can choose).

  • Create a 3D velocity vector field \(\Psi(s)\) to control the velocity of the point \(s \in \mathbb{R}^3\) to track it.

  • Implement joint velocity control, \(\dot{q}=u\) in the manipulator to track this velocity while keeping the orientation constant. You need to specify, through differential kinematics, the linear velocity of the manipulator to match the one from the vector field and also have a term to guarantee the constant orientation. So, given a task function \(r_o(q)\) for the desired pose, you need to establish: $$ J_v(q)u = \Psi(s(q)) \ , \ \frac{\partial r_o}{\partial q}(q)u = -Kr_o(q) $$

PROBLEM 2


  • Implement a second order kinematic control to control the joint acceleration \(\ddot{q}\) of a manipulator to achieve a constant target pose \(T_{des}\) for the end-effector.

  • The code should sample a random target pose, a random start configuration \(q(0)\) and assume zero initial joint velocity \(\dot{q}(0)=0\).

  • You dont need to incorporate any constraint like obstacle avoidance and joint limit.

PROBLEM 3


  • Implement a code that samples 3 random spheres in random positions in the box \(\mathcal{B}\) given by \(-2 \leq x \leq 2\), \(-2 \leq y \leq 2\) and \(0 \leq z \leq 2\) and with a random radius. Ensure that no two spheres are colliding with each other. Sample also a random starting position and a random goal position within these boundaries.

  • Assume velocity control \(\dot{q}=u\). Create a CBF controller to control the 3D position of a robot, modelled as a sphere with radius \(R=0.3\), to go the target position while avoiding collision between with the spheres and the boundaries of the box \(\mathcal{B}\).

PROBLEM 4


  • This problem is a harder version of the previous problem.

  • Create a code that, instead of spheres, create 3 random polyhedras with 6 faces each. The polyhedras should be placed in random poses inside the same box \(\mathcal{B}\) as before. Again, ensure that no two objects are colliding with each other.

  • Our robot now is a box with sides \(\ell_x=0.2, \ell_y=0.3, \ell_z=0.4\). Furthermore, instead of just the linear velocity, we can control its angular velocity vector \(\omega\) as well (e.g., it is a box-shaped omnidirectional drone).

  • Create a CBF controller to manipulate the two velocities \(v,\omega\) to go to the target point while avoiding collision with the objects.

  • Remember that you can compute the distances and witness points, necessary for implementing the CBFs, by using the UAIBot's function compute_dist. Remember also that this function computes the distance, instead of the half-squared distance.
